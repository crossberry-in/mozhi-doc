Learn by running code

Every program below was executed against the v3.1 interpreter before being published — servers were curled, databases were queried, assertions were asserted. Click code on a card to read the full source, or run it yourself:

sh run any example locally 
curl -fsSL https://crossberry-in.github.io/mozhi-doc/install.sh | bash
mozhi run examples/web_hello.mz
info

Server examples (web_hello, web_api) listen until you press Ctrl-C. http_client pairs with them — run the servers first, then the client with the URLs from its header comment.

How verification works

Examples live in the examples/ directory of the docs repository and are re-checked on every interpreter change. The verification pass runs each program, curls every endpoint it exposes, and confirms assertions pass — an example that stops running is an example that stops shipping.
