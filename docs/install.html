Installation

Mozhi runs on Linux, macOS, Windows, and Termux (Android). The installer auto-detects your platform and architecture, so in most cases you can install with a single command.

Quick Install

Step 1: Install the Mozhi interpreter

The interpreter is the binary that runs .si files. It's installed as mozhi-interpreter.

Linux / macOS / WSL / Termux:

curl -fsSL https://github.com/crossberry-in/mozhi-doc/raw/main/install.sh | bash

Windows (PowerShell):

irm https://github.com/crossberry-in/mozhi-doc/raw/main/install.ps1 | iex

Step 2: Install the mozhi-pkg dispatcher

The mozhi command is the unified dispatcher that routes file execution to the interpreter and subcommands to the package manager.

Linux / macOS / WSL / Termux:

curl -fsSL https://github.com/crossberry-in/mozhi-pkg/raw/main/install.sh | bash

Windows (PowerShell):

irm https://github.com/crossberry-in/mozhi-pkg/raw/main/install.ps1 | iex

Step 3: Verify

mozhi version      # Should show the Mozhi Compiler banner
mozhi doctor       # Should show all green checks

Requirements

  • Interpreter: No dependencies (static or system libc + libm)
  • Dispatcher (mozhi): Python 3.8+
  • For C/C++/ASM FFI: gcc or clang
  • For Rust FFI: rustc
  • For GitHub dependencies: git

Manual Installation

If the installer doesn't work, you can install manually:

# Download the interpreter binary
curl -fsSL -o /usr/local/bin/mozhi-interpreter \\
  https://github.com/crossberry-in/mozhi-doc/releases/download/v2.4.0/mozhi-interpreter-linux-arm64

# Download the dispatcher
curl -fsSL -o /usr/local/bin/mozhi \\
  https://github.com/crossberry-in/mozhi-pkg/releases/download/v1.2.0/mozhi

# Download the UI module
mkdir -p /usr/local/lib/mozhi
curl -fsSL -o /usr/local/lib/mozhi/mozhi_ui.py \\
  https://github.com/crossberry-in/mozhi-pkg/releases/download/v1.2.0/mozhi_ui.py

# Make executable
chmod +x /usr/local/bin/mozhi /usr/local/bin/mozhi-interpreter

# Verify
mozhi version
