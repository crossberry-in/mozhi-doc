Installation

Sino runs on Linux, macOS, Windows, and Termux (Android). The installer auto-detects your platform and architecture, so in most cases you can install with a single command.

Quick Install

Step 1: Install the Sino interpreter

The interpreter is the binary that runs .si files. It's installed as sino-interpreter.

Linux / macOS / WSL / Termux:

curl -fsSL https://github.com/crossberry-in/sino-lang-docs/raw/main/install.sh | bash

Windows (PowerShell):

irm https://github.com/crossberry-in/sino-lang-docs/raw/main/install.ps1 | iex

Step 2: Install the sino-pkg dispatcher

The sino command is the unified dispatcher that routes file execution to the interpreter and subcommands to the package manager.

Linux / macOS / WSL / Termux:

curl -fsSL https://github.com/crossberry-in/sino-pkg/raw/main/install.sh | bash

Windows (PowerShell):

irm https://github.com/crossberry-in/sino-pkg/raw/main/install.ps1 | iex

Step 3: Verify

sino version      # Should show the Sino Compiler banner
sino doctor       # Should show all green checks

Requirements

  • Interpreter: No dependencies (static or system libc + libm)
  • Dispatcher (sino): Python 3.8+
  • For C/C++/ASM FFI: gcc or clang
  • For Rust FFI: rustc
  • For GitHub dependencies: git

Manual Installation

If the installer doesn't work, you can install manually:

# Download the interpreter binary
curl -fsSL -o /usr/local/bin/sino-interpreter \\
  https://github.com/crossberry-in/sino-lang-docs/releases/download/v1.0.0/sino-linux-arm64

# Download the dispatcher
curl -fsSL -o /usr/local/bin/sino \\
  https://github.com/crossberry-in/sino-pkg/releases/download/v1.2.0/sino

# Download the UI module
mkdir -p /usr/local/lib/sino
curl -fsSL -o /usr/local/lib/sino/sino_ui.py \\
  https://github.com/crossberry-in/sino-pkg/releases/download/v1.2.0/sino_ui.py

# Make executable
chmod +x /usr/local/bin/sino /usr/local/bin/sino-interpreter

# Verify
sino version
