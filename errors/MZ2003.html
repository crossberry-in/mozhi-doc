MZ2003 · Type Error · WARNING
Narrowing Cast
A type cast may lose data (e.g., int64 to int8, float to int).

Cause

Casting from a larger type to a smaller type, or from float to int, may result in data loss.

Examples

Example 1

Problem:

big = 1000
small = int8(big)

1000 does not fit in int8 (-128..127).

Fix:

Use a larger type: small = int16(big)

Example 2

Problem:

x = 3.99
y = int(x)

Fractional part is lost (3.99 becomes 3).

Fix:

This may be intentional. Use floor(x) or round(x) for clarity.

Hint

Check if the value fits in the target type range.

Suggestion

Use a larger type, or verify the value is within range.
