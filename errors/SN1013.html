SN1013 · Parse Error · ERROR
Expected Closing Brace
A closing brace } was expected but not found.

Cause

A block was opened with { but never closed with }.

Examples

Example 1

Problem:

fn add(a, b) {
    return a + b

Missing } at the end of the function.

Fix:

Add the closing brace } at the end of the block.

Hint

Every { must have a matching }.

Suggestion

Add the missing } at the end of the block.
