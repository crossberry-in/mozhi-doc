SN3002 · Runtime Error · ERROR
Index Out of Bounds
An array index was accessed that is outside the valid range.

Cause

The index used to access an array element is negative or greater than or equal to the array length.

Examples

Example 1

Problem:

arr = [1, 2, 3]
echo(arr[5])

arr has 3 elements (indices 0-2); index 5 is out of bounds.

Fix:

Check the index before accessing: if 5 < len(arr) { echo(arr[5]) }

Hint

Array indices are 0-based. Valid range: 0 to len(arr)-1.

Suggestion

Check the index with index < len(arr) before accessing.
