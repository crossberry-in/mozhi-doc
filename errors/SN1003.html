SN1003 · Parse Error · ERROR
Type Mismatch
The value assigned to a variable does not match the declared type.

Cause

A variable with an explicit type annotation was assigned a value of an incompatible type. Sino performs static type checking at compile time.

Examples

Example 1

Problem:

count: int = hello_string

A string value is assigned to a variable declared as int.

Fix:

Assign an integer value: count: int = 42. Or change the type to string.

Example 2

Problem:

flag: bool = 1

An integer is assigned to a bool variable (no implicit conversion).

Fix:

Use a boolean literal: flag: bool = true

Hint

Sino does not implicitly convert between unrelated types. Use explicit casts for numeric types.

Suggestion

Check the declared type and ensure the assigned value matches.
