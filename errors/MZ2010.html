MZ2010 · Type Error · ERROR
Field Not Found
A struct field was accessed that does not exist on the struct type.

Cause

The field name used in dot notation does not match any field declared in the struct.

Examples

Example 1

Problem:

struct User { name: string, age: int }
u = User { name: Alice, age: 30 }
echo(u.nme)

nme is misspelled (should be name).

Fix:

Use the correct field name: u.name

Hint

Check the struct definition for available fields.

Suggestion

Use the correct field name, or add the field to the struct.
