SN2002 · Type Error · WARNING
Variable Shadowing
A variable was declared with the same name as an existing variable in the same scope.

Cause

Redeclaring a variable in the same scope shadows (hides) the previous declaration. This is allowed but may indicate a mistake.

Examples

Example 1

Problem:

x = 10
x = 20
x = hello_string

x is reassigned with a different type.

Fix:

Use a different variable name for the new value.

Hint

Shadowing is legal but can cause confusion. Use distinct names.

Suggestion

Use a different variable name.
