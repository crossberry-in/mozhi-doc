SN2001 · Type Error · ERROR
Type Inference Failure
The compiler could not infer the type of an expression from its context.

Cause

Type inference requires enough information to determine the type. If an expression is too ambiguous (e.g., an empty array with no context), the compiler cannot infer the type.

Examples

Example 1

Problem:

empty = []

Cannot infer the element type of an empty array.

Fix:

Provide a type annotation: empty: [int] = []

Hint

Add an explicit type annotation when the type cannot be inferred.

Suggestion

Annotate the variable with the expected type.
