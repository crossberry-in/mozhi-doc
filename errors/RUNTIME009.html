RUNTIME009

runtime error

error
verifiedsince v3.2.0 categoryruntime terminalstable code

What it means

The central engine classifies every top-level error message to a code. Messages that match no pattern receive this generic code so machine readers always see a valid `code` field.

Trigger condition

Any runtime error whose message has no dedicated code yet (raised deep inside a built-in or native module without an AST position).

Minimal failing example

(any runtime failure whose message is not yet mapped)

Verified fix

(diagnose from the message text; the local diagnosis and docs index still apply)

The full original message is always preserved in the `reason` field.

Run mozhi --json run app.mz to get the same information as machine-readable JSON (schema mozhi.diagnostics.v1), or --verbose to also show grouped related diagnostics. See the CLI reference.

Suggested fix

Treat as a normal runtime error: read the message, check the docs index, and if it resembles a known pattern report an issue so it can get a dedicated code.
