Mozhi

Programming Language
Version 2.0

Fast • Safe • Modern

Read the Specification Install

Mozhi is a statically-typed programming language designed for building fast, safe, and maintainable software. This is the official documentation site, hosted on GitHub Pages.

Key Features

Static Typing

Compile-time type safety with automatic type inference. Catch errors before your code runs.

Native Performance

Compiled to native machine code. Runs at full speed on Linux, macOS, Windows, and Android.

Memory Safe

Automatic garbage collection and ownership tracking prevent memory errors.

FFI Support

Call functions written in C, C++, Assembly, and Rust through a stable ABI.

Modern Syntax

Clean, consistent syntax with braces, pattern matching, and trait-based polymorphism.

Package Manager

Built-in package manager with semantic versioning, lock files, and GitHub integration.

Quick Example

# Hello World in Mozhi
echo("Hello, World!")

# Variables with type inference
name = "Mozhi"
age = 20

# Functions
fn add(a, b) {
    return a + b
}

# Pattern matching
match age {
    18 => echo("Just became an adult")
    n if n > 18 => echo("Adult")
    _ => echo("Minor")
}

# Structs and traits
struct User {
    name: string
    age: int
}

trait Greetable {
    fn greet()
}

impl Greetable for User {
    fn greet() {
        echo("Hi, I'm ", name)
    }
}

user = User { name: "Alice", age: 30 }
user.greet()
