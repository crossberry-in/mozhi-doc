One language.
Full-stack development.

Mozhi is a fast, safe, C-family scripting language with a native HTTP server, HTML templates, JSON, a filesystem sandbox and SQLite — all inside the interpreter runtime. No PHP, no Python bridge, no child processes.

mozhi a complete web app — native server, no dependencies 
import web
import json

let app = web.create({ log: true })

app.get("/", fn(req, res) {
    return res.html("<h1>Hello from Mozhi</h1>")
})

app.post("/api/calculate", fn(req, res) {
    let data = req.json()
    if data.a == null or data.b == null {
        res.status(422)
        return res.json({ error: "a and b are required" })
    }
    return res.json({ result: data.a + data.b })
})

app.listen("127.0.0.1", 8080)

Native modules, zero bridges

Every capability below ships inside the interpreter itself — the same process, the same runtime, no glue code and no external interpreters.

Routing with path parameters, middleware chains, static files, cookies, custom 404/500 handlers, request limits and graceful shutdown.

Prepared statements only, tracked migrations, explicit transactions. User input can never become SQL.

Why Mozhi

speed

Two runtimes, one language

A tree-walking interpreter in C for immediate feedback, and mozhi-fast, a bytecode VM in Rust, for throughput — the same syntax, the same standard library.

shield

Security by default

The v3.1 hardening pass bounds and time-limits HTTP headers, validates every filesystem path through its nearest real ancestor, and ships with an adversarial regression suite plus sanitizer CI.

terminal

Real toolchain

mozhi run, dev with auto-reload, serve, test, fmt, lint and build — plus mozhi.toml project configuration.

inventory_2

Standard library in itself

String, collection, crypto, regex and HTTP utility modules are written in Mozhi and installed with mozhi pkg — read them to learn the language.

verified

Every example on this site is executed against the v3.1 interpreter before it ships. The snippets you see run exactly as printed — start with the examples gallery.
