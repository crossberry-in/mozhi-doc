Mozhi

Programming Language
Version 2.4.0

Fast • Safe • Modern

Read the Specification Install Libraries

Mozhi is a programming language with a tree-walking interpreter implemented in C, a beautiful TUI in Go, and a library package system. This is the official documentation site, hosted on GitHub Pages.

What's New in v2.4.0

File I/O

read_file(), write_file(), file_exists(), list_dir() — read and write files from Mozhi programs.

Shell & Multi-Language

run(cmd), run_c(), run_cpp(), run_py(), run_sh(), run_mz() — execute shell commands and run files in other languages.

Smart Imports

import http from "mozhi-http" — libraries auto-download from GitHub on first use. Three import styles: wildcard, namespace, and file path.

HTTP Static Files

http_serve_static(path, dir) — serve index.html, CSS, JS, and other static files. Plus http_run_mz/c/py/sh() for dynamic endpoints.

Library System

5 official libraries (112 functions): html, http, json, math_utils, strings. Install with mozhi add or just import directly.

Cross-Platform

Pre-built binaries for Linux (x86_64/ARM64), macOS (Intel/Apple Silicon), Alpine, and Windows. Closed-source — only binaries are published.

Key Features

Tree-Walking Interpreter

Implemented in C with cross-compilation via Zig. Runs on 7 platform targets including static musl builds for Alpine.

Go TUI CLI

Beautiful glassmorphism UI built with Bubble Tea and Lip Gloss. Commands: build, run, test, fmt, lint, add, update, repl, and more.

Modern Syntax

Clean syntax with braces { }, fn, const, match, and/or, string methods, and pattern matching.

Networking Builtins

server_listen(), http_get(), socket_send/recv() — build HTTP servers and clients directly in Mozhi.

String & Array Methods

.upper(), .lower(), .split(), .replace(), .contains(), .slice(), .push(), .pop(), and more.

GitHub Actions CI/CD

Automated builds for all platforms. Push to trigger a new release with binaries published to the public mozhi-doc repo.

Quick Example

# Hello World in Mozhi
echo("Hello, World!")

# Variables with type inference
name = "Mozhi"
age = 20

# Functions
fn add(a, b) {
    return a + b
}

# Pattern matching
match age {
    18 => echo("Just became an adult")
    n if n > 18 => echo("Adult")
    _ => echo("Minor")
}

# Structs and traits
struct User {
    name: string
    age: int
}

trait Greetable {
    fn greet()
}

impl Greetable for User {
    fn greet() {
        echo("Hi, I'm ", name)
    }
}

user = User { name: "Alice", age: 30 }
user.greet()
