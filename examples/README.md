# Sino — Examples

This directory contains sample Sino programs (`.si` files) to help you learn the language.

---

## Files

| File | Description |
|------|-------------|
| [`hello.si`](hello.si) | Hello World and basic syntax demo |
| [`basics.si`](basics.si) | Variables, constants, control flow, and functions |
| [`factorial.si`](factorial.si) | Recursive factorial function |
| [`fibonacci.si`](fibonacci.si) | Recursive Fibonacci sequence |
| [`classes.si`](classes.si) | Object-oriented programming with classes |
| [`match.si`](match.si) | Pattern matching with `match`/`case` |
| [`math.si`](math.si) | Math operations using built-in functions |
| [`sorting.si`](sorting.si) | Sorting algorithms (bubble sort) |

---

## Running the Examples

After installing Sino (see the [Installation Guide](../INSTALL.md)), run any example with:

```bash
sino hello.si
sino fibonacci.si
```

---

## Hello World

The simplest Sino program:

```sino
echo "Hello, World!"
```

Save as `hello.si` and run with `sino hello.si`.
