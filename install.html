Installation

Mozhi runs on Linux, macOS, Windows, and Termux (Android). The installer auto-detects your platform and architecture, so in most cases you can install with a single command.

Install with npm boltfastest on Linux

The official npm package is the fastest way to get Mozhi on Linux (x86_64 or ARM64). One command installs two equivalent commands — the canonical mozhi and the short alias mz — from fully static binaries bundled inside the package (works on glibc distros, Alpine and Termux/Noxs-style chroots; no compilation, no postinstall downloads).

npm install -g @crossberryweb/mozhi

npm requirements

  • Node.js ≥ 22 — any supported release line: 22.x (Maintenance LTS), 24.x (LTS) or 26.x (Current). Node.js 14, 16, 18 and 20 have reached end of life and are no longer supported; on those lines the launcher still works but prints a one-time end-of-life notice. Node.js only runs the tiny launcher shim — the interpreter itself is a fully static native binary.
  • npm (ships with Node.js)

Verify

mozhi --version     # Mozhi 3.2.0
mz --version        # identical — mz and mozhi are the same interpreter

Both commands always behave identically: same version, same flags, same exit codes.

Upgrade / uninstall

npm install -g @crossberryweb/mozhi@latest   # upgrade
npm uninstall -g @crossberryweb/mozhi        # removes both commands

macOS / Windows / WSL: the npm package currently bundles Linux binaries only — use the installer script below on those platforms. It installs the same mozhi command natively.

Quick Install

Step 1: Install the Mozhi interpreter

The interpreter is the binary that runs .mz files. It's installed as mozhi-interpreter.

Linux / macOS / WSL / Termux:

curl -fsSL https://github.com/crossberry-in/mozhi-doc/raw/main/install.sh | bash

Windows (PowerShell):

irm https://github.com/crossberry-in/mozhi-doc/raw/main/install.ps1 | iex

Step 2: Install the mozhi-pkg dispatcher

The mozhi command is the unified dispatcher that routes file execution to the interpreter and subcommands to the package manager.

Linux / macOS / WSL / Termux:

curl -fsSL https://github.com/crossberry-in/mozhi-pkg/raw/main/install.sh | bash

Windows (PowerShell):

irm https://github.com/crossberry-in/mozhi-pkg/raw/main/install.ps1 | iex

Step 3: Verify

mozhi version      # Should show the Mozhi Compiler banner
mozhi doctor       # Should show all green checks

  • For C/C++/ASM FFI: gcc or clang
  • For Rust FFI: rustc
  • For GitHub dependencies: git

Manual Installation

If the installer doesn't work, you can install manually — the interpreter is a single fully static binary, no dispatcher or Python needed:

# Download the interpreter (v3.2.0, static — works on any Linux)
curl -fsSL -o /tmp/mozhi \\
  https://github.com/crossberry-in/mozhi-doc/releases/download/v3.2.0/mozhi-interpreter-linux-arm64

# Install as 'mozhi' (canonical), the 'mz' short alias, and keep the legacy name as a symlink
sudo mv /tmp/mozhi /usr/local/bin/mozhi
sudo chmod +x /usr/local/bin/mozhi
sudo ln -sf mozhi /usr/local/bin/mz
sudo ln -sf mozhi /usr/local/bin/mozhi-interpreter

# Verify
mozhi --version
mz --version
